# 🕵️‍♀️ Credit Card Fraud Detection Model

An imbalanced classification project using Python and Power BI to predict high-risk financial transactions.

## 📄 Final Report
[Download Full Executive Summary and Visuals](report/final_fraud_report.pdf)

## 🧪 Source Code
Main training script: `scripts/fraud_model.py`  
Model evaluation and ROC curve: `scripts/generate_report.py`

## 📊 Key Features
- SMOTE for balancing rare fraud cases
- Logistic Regression vs. Random Forest comparison
- ROC curve visualization (AUC: 0.95 vs 0.98)
- Power BI dashboard with fraud insights

## 📁 Project Structure
- `data/` – raw dataset
- `models/` – saved `.pkl` models
- `scripts/` – training and reporting scripts
- `visuals/` – ROC curve and dashboard screenshots
- `report/` – final PDF report

## 🚀 Tools Used
Python, scikit-learn, matplotlib, Power BI, GitHub, PyCharm
